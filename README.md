# STACloud Maintenance

Trang thong bao bao tri cho STACloud.

## Chay bang Node.js

```bash
npm run dev
```

Mac dinh trang chay tai `http://localhost:8080`. Neu port `8080` dang ban,
server se tu thu cac port tiep theo nhu `8081`, `8082`.

Co the doi port bang PowerShell:

```powershell
$env:PORT = "8081"
npm run dev
```

## Chay bang Go

```bash
npm run go:dev
```

Lenh Go yeu cau moi truong da cai Go 1.22 tro len.
